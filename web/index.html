// core features

不只是终端，是 Claude Code 的工作台。

围绕「标签 = 工作流容器」重新设计，把开会话、恢复、找会话这些重复劳动全部自动化。

会话绑定 · 一键恢复

标签出生即钉死一个 session UUID，首次 --session-id 创建、此后 --resume 精确命中。点一下标签，pwsh 自动落到对应路径并恢复会话。

栈式会话 · /clear 不丢历史

/clear 换了新会话 id？标签会把它压入会话栈、栈顶前移，标签栏依旧是同一个，下拉里随时翻回 clear 之前那段长对话。

状态徽标 · 一眼看谁该处理

hook 驱动的状态点：运行中 / 需决策 / 完成 / 空闲。多个会话并行时，橙色脉冲一眼锁定「正在等你批权限」的那个。

分组 · 保存 · 恢复

按路径分组管理标签，可整组保存快照、一键恢复整套工作流（含每个标签的会话栈与当前会话），下班关机也不怕丢现场。

PowerShell 7 · 真 ConPTY

基于 node-pty + ConPTY 的原生体验，UTF-8 无乱码、reflow 不错位、xterm 渲染。先起 pwsh 再喂 claude，Ctrl+C 退出后还是可用的 shell。

不动你的全局配置

会话追踪 hook 用 --settings 单实例挂载，不污染 ~/.claude/settings.json。会话按 UUID 全局搜，中文路径也不会串。

锁定 cc 版本 · 禁用自动升级

一个开关写入用户级环境变量 DISABLE_AUTOUPDATER=1，系统级生效——此后所有新起的 Claude Code 都不再偷偷自动升级，团队统一锁版本、避免版本漂移带来意外变更。

  • 写进 HKCU\Environment，对本终端外的 cc 也生效
  • 关闭时只清除自己写入的，不动你原有配置
